# AI API Client

A beginner-friendly Python command-line client for sending prompts to an AI API and returning a clean JSON response.

> Project status: setup phase. The CLI and API integration will be added step by step.

## Planned technologies

- Python 3
- `requests` for HTTP requests
- `python-dotenv` for local environment variables
- Git for version control

## Project structure

- `main.py` — command-line entry point (to be implemented)
- `client.py` — AI API client class (to be implemented)
- `.env` — local configuration and API credentials; never commit this file
- `requirements.txt` — Python package dependencies
- `.gitignore` — files Git should ignore
